藏头 v0.2 真机试验 · 卡上编辑的缩放方式

本页只用来试，不是正式功能。结果请在页面最下面的「记录」里填，再点「生成摘要」截图或复制发给我。上方黑条会一直显示视口数值和最近一条事件，键盘弹起时也看得到。

0 · 测试步骤（照着点、看、记）

  1. 先看「1 环境」：记下 UA、屏宽、深浅色是否 dark。把手机切到深色模式再回来，看「深色」那一行是否自己变（不用刷新）。
  2. 方式一 / 二 / 三（三张卡，文字内容相同）：每张卡里每个虚线框依次点一下，再用中文输入法（拼音）各打几个字，打到候选词上屏。每个框都要看：
    • 光标（红色竖线）看得见吗？位置和字对得齐吗？（假设 C、A）
    • 长按选字 / 拖动选区，手柄和选区位置对吗？（假设 A）
    • 拼音候选条出现的位置贴着输入处吗？（假设 A；方式二可能错位）
    • iOS：点击后整个页面有没有被放大？看黑条里 vv.scale 是否变成大于 1 的数。（假设 B）
    • 打字过程不能被打断、不丢字。「词」框的文字应该变成首字母大写。（假设 E）
  3. 「重写」开关：把「组字结束后改写值并恢复光标」勾上，再在任一框里用拼音打字，看光标是否跳到最前 / 最后、输入法是否被打断、日志里 compositionstart / end 是否成对出现。再取消勾选，对比一次。（假设 E）
  4. 键盘：点最下面的框，键盘弹起后黑条里 vv.h 变小，日志会记录「控件是否在可视区内」。（给假设 F 一个早期读数）
  5. 「5 横滑区」：在空白处 / 在输入框上按住后左右滑；再从屏幕最左边缘向右滑一次。每次看计数里有没有 touchcancel、能不能切页。在输入框里长按拖选文字时页面不该滑走。（假设 J）
  6. Android 大字体：先在默认字体下记下「1 环境」里两个「文字缩放比」；再到系统设置把字体调到最大，重新打开本页，对比这两个值是否明显变大，以及三张卡里的字是不是比镜像框大。（假设 D）
  7. 每一项在「6 记录」里选结果、写一句话。有异常就截图（带上黑条）。

PC 模拟器同样做一遍，记录里区分三端：PC 模拟器 / Android / iOS（摘要里自动带上 UA）。

2 · 方式一：直接按屏宽算尺寸

  
所有数值 × k（k = 卡宽 / 1080），控件不在缩放容器里。字号含 < 16px。

  

  


  
3 · 方式二：按 1080 排好再 transform: scale(k)

  
同样的卡，整体放进 1080 宽容器后缩放。对比光标、选区手柄、候选条位置是否错位。

  

  


  
4 · 方式三：直接算尺寸 + 控件 16px 局部 scale（iOS 放大退路）

  
控件字号固定 16px，再用 transform 缩到目标大小；视觉应与方式一相同。若 iOS 上方式一会放大页面而这里不会，退路成立。

  

  


  

  
5 · 横滑区（假设 J）

  
区域样式 touch-action: pan-y。共 3 页，左右滑切页；页里有输入框。
