# 门户滚动的模拟测试

样稿通过时用的检查办法，供实现方自测、复审方复验。不进 `npm test`（要浏览器）。

- `manual-clock.js`：手动时钟。必须在页面自己的脚本之前加载；它接管定时器与时间，之后用 `__tick(毫秒)` 推进。隐藏的浏览器窗格里定时器不走，所以要它。
- `scroll-sim.js`：八种下滑节奏的模拟。页面加载后执行，`__S.go("A")` 跑一种节奏并返回一行结果；节奏代号 A、B、C、D、E、F（鼠标）、K（按住方向键）、T（触控板大滑），定义在文件里的 `PAT`。

用法：起一个本地静态服务，页面 `<head>` 最前面引 `manual-clock.js`；视口设成 1280×800（窗格没有尺寸时页面不会动）；每跑一种节奏前清 `localStorage` 并重新加载页面。

通过标准（样稿 11-23 的结果）：八种节奏都「到结束页」「全部显示完」，全程 37 到 55 秒。另外手工量过的几项见 `../DESIGN.md`「鼠标滚轮下滑的检查」。

脚本按样稿的元素名读状态（`#word`、`#parts`、`#rg`、`#gc`、`#fin`、`.stage`、`.seg`、`.rg-cap`）。正式页面若改了这些名字，脚本要跟着改。
