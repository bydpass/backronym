2026-11-09（多伦多）建立范围契约；2026-11-11整理入口。保全规则仍有效；收录范围已按下方11-11新决定替代旧规则，当前执行队列见[T19](../plans/v00.03.00/T19.md)。后半部分为当时实施记录，不作为今天的状态。

## 数据与展示

正式单词统一存 `[拼写, 带词性分组的释义, 冠词, 注释]`。前两位兼容旧消费者；第三位保持原有冠词位置；第四位是新增的独立注释。旧二/三列仍可由 `CORE.entryData(item, lang)` 读取。未知扩展位不得丢弃。

- en / la：拼写、释义、注释；冠词存空串。拉丁语有语法性别，只是不展示冠词。
- fr / de / es / it：需要且已知冠词的名词显示【小字号冠词块】拼写、释义、注释；其他词条不强加冠词。冠词未知保持空值，不能猜。
- 冠词不是拼写的一部分，不占藏头格，不参与首字母匹配。保留复数、省音和多性别冠词，如 les、l’、los / las、i / gli / le；用户举例不是枚举白名单。
- 注释用于用法、语域等补充信息。此次没有可靠独立注释来源，填空串；不把审核理由/标记批量当作用户注释，不从原释义中破坏性拆解。
- 原始词性、性别、来源、审核元数据留在原始候选与复审资料中。正式词库仍保留释义词性；没有删去底层审计信息。
- `CORE.entryData` 返回 `{spelling, meaning, article, note}`，供 T22 使用。这是基础读取接口；后续界面与导出接入已有实现，其当前验收状态按T19联动任务核对。

### 后续已有的义项冠词扩展

同一拼写的多组名词义项可分别对应冠词，第三列用 `|` 按名词组顺序对齐，例如 `n.书|n.磅` 对应 `le|la`。附加义项仅接受人工定稿，不把机器候选直接写入成品；这是当前已实现扩展，复审状态见T19-05。

## 范围（2026-11-11新决定，待实现）

全部六语统一按义项准入：功能词、介词和感叹词用法彻底排除；有对应形容词的副词用法彻底排除，不设“意思变化”豁免。不能仅凭后缀判定对应关系。同形的其他实义保留。数词仅手动查询，不入任何推荐池。

普通人名独立查询表，不默认推荐也不参与展开候选；四列为 `[原拼写, 译名, m/f, 来源语言]`。语言按来源证据归属，IPA仅为线索，不因多语言同译名默认en。文化人物、地点、事件、政体有独立文化含义时可另作为历史文化义项审核。

默认候选以日用、创作为主；专业、历史文化主动展开，手动输入可查询。初始权重：日用100、创作90、人文专业60、自然专业55、历史文化60、普通人名查询1；数词不参与推荐评分。类别闸门先于权重，不把人名混入低概率随机候选。

六语尽量覆盖同一生活/创作主题；拉丁语限今天用于二名法命名和文学创作的常见词。旧专业前40%、字幕覆盖率门槛驱动选词和自动扩词停止法作废；词频仅作排序与诊断。旧源料与审核结论保留，但需要重新判定新范围准入，不能把旧全量词库视为新范围验收通过。

完整分片、义项身份、权重及查询契约见[T19选词规则](../plans/v00.03.00/T19_SELECTION.md)，首批250个概念位置见[核心清单](../plans/v00.03.00/T19_CORE.md)。词表按语言→用途类别→主题/领域分片（每片最多300行），不制作超大合并TSV作为权威数据源；语法词性继续作为条目字段保留。尚未改造现有成品、旧审核表或生成器。

已经保存或用户手填的文字不因范围改变被禁用、迁移或删除。范围外用法不由词库提供，不等于禁止用户自写。附着代词及非独立形式需要词义证据判断；查询索引不得借同形实词回填已排除用法。

## 旧实现与口径（待按新范围改造）

- `scripts/lexicon/scope.mjs`：共享范围规则，迁移时保留注释及未知扩展位。
- `scripts/build-dict.mjs`：英语生成时移除功能词组，输出四列。返工后（SCOPE-R1 / R2）：功能词性的行在跨词性去重之前跳过；只有功能词性加领域义项的词整词不收（清单打在生成日志里，待裁定）；短语按「词汇」认组成词、释义不按范围筛，所以 account for 这类短语照收。**英语成品只能由 `npm run dict` 从源生成**，`apply-scope.mjs` 不迁移英语。
- `scripts/lexicon/audit-review.mjs`：审核预期、抽样池、合并后核对都按复审后词性应用同一范围（SCOPE-R3）。
- `scripts/build-lexicon.mjs`：在 applyReview 之后按有效词性过滤成品与待审队列；完整候选表保留。输出四列，报告附范围版本和剔除数量。
- `scripts/lexicon/apply-scope.mjs`：默认只读生成清单；`--write` 对已有成品局部迁移并逐文件备份校验。过滤被删除词的变形索引目标；保留版权头、断词数据。不会重新抽取或覆盖普查分片。
- 当前成品沿用现有词性；五语种未来审核清单另按冻结源表 + T18 有效词性统计。二者不能混称为 T19 合并后的最终词库。
- 旧字幕词频选词和覆盖率仍保留为历史代理指标。新范围主动排除高频功能词，不能继续拿全词性字幕覆盖率的旧门槛验收命名候选；未来选词算法调整须单独说明分母。
