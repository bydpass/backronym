## 二、产品定义（用户确认，未改写）

- 面向 OC 妈与同人女的「拼字工具」：用一个概念词描述一个角色（如 LIFE），再逐个字母定义它的组成。产物是一张可编辑的图。
- 路线「4 + 1」：**4 · 在图上编辑**——编辑时看到的就是最终那张图；**1 · 词库是灵感，不是答案**——先打每个字母的关键词，再出词库。
- 单图与列阵都是产物，默认单图。
- 绝对不做：账号、社区、信息流；AI 生成；背单词 / 教学。

### 关键技术做法
- **排版只算一次**（D5 / D14）：`core.js` 的 `layoutCard` / `layoutGrid` 输出 1080×1440 坐标的版式框，Canvas 导出和 DOM 卡都按同一份框画，编辑所见即导出所得。
- **逐字画字距**：Canvas 的 `letterSpacing` 要 Chrome 99+，基线是 Chrome 61，所以用 `CORE.charX` 逐字定位。
- **像素回归**：`scripts/export-hash.js` 用固定草稿导出 52 张图算哈希；从第 2 批起每批都要求与参考值 `9b530062…` 一致或逐行解释。
- **可被变异杀死的测试**：`npm test` = `test-blocklist.mjs` + `test-core.mjs` + `test-app.mjs`（审查修复时加入，从真实 app.js 截取函数体配替身）；每批把关键函数故意改坏，确认测试报错。
- **按字处理文字**：字距、折行、截断、粘贴、逐字画统一用 `CORE.textUnits()`，不按 UTF-16 单元，避免拆开 emoji。
