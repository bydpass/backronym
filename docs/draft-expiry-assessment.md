# 草稿 18 小时过期：实现规则与历史评估

> 2026-10-21：已与用户讨论并实现，随 v00.02.00 收尾提交。当前规则以本节为准。

## T10 的能力边界

端 API 没有取消请求或条件写入（CAS）。校正依赖迟到调用返回、页面仍运行，以及后续端接口可用；迟到副作用发生到补写完成之间也存在窗口。因此不能承诺关闭页面后的校正、端永久不可写时的落盘，或跨页面同时写入的严格隔离。超时不算保存成功，原有本地兜底和未知原稿覆盖闸门保留。本轮通过受控时序验证同一会话的最终校正，不代表容器真机已验收。

## 第六批提示收尾

清理失败使用“部分存储清理未完成，将重试。”，不据清理失败推断草稿已过期。空稿清理完成后不显示提示（11-04 用户定）；恢复时的读取失败状态仍保留，未保存和无法保全警告不会被清理成功覆盖。

## 已确认的行为

- 连续 18 小时没有新的内容保存即过期；以草稿 `t` 计算 `t + 64,800,000ms`，时间缺失、无效或非正数直接失效。
- 内容变化并至少一路确认保存成功才更新页面的到期时间。同内容重复保存、打开/恢复、切主题、切当前格、导出不续期；视图是持久字段，切换视图属于更新。
- 到期清空当前作品（含内存配图、裁剪和未保存的导出预览）、主草稿和过期备份；保留主题等无关偏好，以及已保存到相册/设备的成品。
- 页面运行时定时检查；挂起后首次交互、回前台和打开时检查。关闭期间不能运行清理代码，故下一次打开先拒绝恢复过期内容再清理。
- **不设旧稿宽限**。用户最新指令：“不存在功能上线前拥有的草稿，直接销毁即可”。此前一次性 18h 宽限建议作废。

## 实现

2026-11-04 T16 只迁移控制器位置，存储引擎 `draft.js` 未改。随后第六批已实现 T10（迟到端操作）与 T11（轮询收束），已由 Claude 审核通过；纯拆分和行为修改分开记录。下文历史分析中的 `app.js` 草稿函数现位于 `app-draft.js`，事件绑定仍在 `app.js`。

- `app/assets/draft.js`：两路存储读取与筛选、18h 判定、定向删除、端操作队列；不碰 DOM。
- `app/assets/app-draft.js`：内容去重、保存状态/到期时间、定时与交互检查、清空编辑状态、取消旧操作结果。
- v00.02.01（T23）起主键为 `backronym-draft-v2`，新增恢复副本键 `backronym-draft-v2-rescue`：存原文字符串的数组，最多 3 份、同字节去重，每份按自身 `t` + 18 小时到期、不续期。读到原文却套用失败、某一侧读失败后重读到原稿，或两侧读到字节不同的有效稿时，第一次覆盖那份原稿之前先存进副本（逐侧读回确认；满了算保全失败，不挤掉任何一份）。旧版 `acronym-draft-v1` 与 `acronym-draft-v1-bak` 只用于定向删除、从不读取，删除失败下次清理重试。没有增加依赖或后台服务；普通更新仍保留未知顶层字段。下文凡提到旧键名、`-bak`、旧格式迁移与备份的，以本条为准。
- 每次删除前重读对应键，只删除仍过期的数据，不用 `clearStorage`。端修改任务正常串行；单次端调用等待满 1500ms 后终止所属任务、放行后续任务，超时任务的迟到读取不能继续触发修改。已经发出的写入/删除无法取消：迟到完成时按该键本会话最后发出的目标校正（主稿与副本分开），沿用原始字节与时间戳；到期目标改走重读清理。相同且仍有效的目标不重复补写，避免接口一直慢时无限追加任务。删除失败提示并重试，过期副本始终不能恢复。
- 无已保存主稿、无待到期副本、无待核实原稿且上次清理成功时停止期限轮询；清理结果返回后重新计算。主稿/副本到期和清理失败保留定时检查，回前台与获得焦点仍调用复核。
- 延迟读取端存储后再读本地最新值，避免等待读取期间本地更新被旧快照覆盖。临近到期不足400ms的编辑立即保存，不再等防抖。

## 底部文案与状态

> 草稿在本设备临时保存，连续 18 小时未更新即过期并清除。关闭页面期间到期，下次打开时清除。配图不保存，重要作品请及时导出。

下一行显示本地时间的“预计清除：…”；保存未确认、读取失败、删除失败均显示真实状态。清空后不再显示旧到期时间。新增汉字已对照现有 `scripts/.cache/fonts/chars.txt`，未超出清单，未安装或重建字体。

## 验证与限制

- `npm test` 包含新 `test-draft.mjs`，以假时钟/内存存储验证期限、双存储、失败、迟到写入和续期。
- `test-draft-browser.mjs` 使用已安装 Playwright、新端口与新浏览器上下文，验证真实页面恢复、自动到期、后台恢复、状态文案与新建；运行方法在脚本头。
- 仍需 PC 模拟器、Android、iOS 验证端存储与真实输入法。浏览器合成事件不是设备验收。
- 设备时钟变化影响期限；浏览器关闭/挂起、进程被杀时不能保证立即物理删除。不可将本功能作为安全擦除承诺。
- 端 API 无原子比较删除/跨页面锁，删除前重读降低误删风险，但不承诺多个窗口严格并发一致性；已有存储的单稿模型未改为协作编辑。
- 已发出的端能力调用不能取消；到期后停止后续发送并丢弃旧结果。相册里已保存的成品不删除。
