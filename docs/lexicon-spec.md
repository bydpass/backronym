## 1. 问题

2026-11-19 对「逐词审定三表」1,261 行的检查查出两类错误。实验把它们的来源分开了：

**漏词**（约 90 个常用词整词缺席）

| 原因 | 例子 | 实测 |
|---|---|---|
| 写法同时是别的词的变形，判歧义，次数整笔不给 | 法 sens（sentir）、西 calle（callar）、意 giro（girare） | 字幕表只有「写法 + 次数」，没有原形和词性 |
| 词典里另有短语或副词词条，被当功能词整词否决 | 法 tonnerre（短语）、faux、sévère，德 mies（副词） | |
| 排在 5,000 名额边界外 | 法 fontaine 5039、marron 5214、berger 5052 | 不是歧义问题 |
| 屏蔽器挡住 | 意 madonna | 不是选词问题 |

**名次虚高**（约 15 个）

| 原因 | 例子 | 实测 |
|---|---|---|
| 百科语域，且百科按 2 倍权重计 | 西 estado 50、意 era 529、dato 538、ora 385 | 字幕次数为 0 或近 0，名次全来自 500 句百科 |
| 写法没登记为变形，整笔给了同形词 | 意 faro（farò 去重音）、verro（verrò），德 Rum（herum） | |
| 「另一原形罕见」的判断误判 | 德 Suche（ich suche）、ketten、mauern | |
| 专名同形 | 西 cristo、意 satana | |

> 修正：本文件初稿说 estado 的字幕次数「整笔给了名词」，实测是 0，虚高来自百科。

## 3. 目标数据模型

五种记录。每个字段标明现状：**有**、**丢**（源里有，抽取时没留）、**无**（没有数据来源）。

### 3.1 词条（一个词）

| 字段 | 说明 | 现状 |
|---|---|---|
| 语言 | fr、de、es、it、la、en | 有 |
| 规范写法 | NFC；德语名词与专名按源大写，拉丁带长音 | 有 |
| 词性 | noun、verb、adj、adv、pron、num、name | 有 |
| 同形区分号 | 维基词典的词源编号，用来分开 livre「书」与 livre「磅」 | **丢** |
| 词条号 | 稳定标识；现在由写法与词性推出，加入区分号后要重算 | 有，需改 |

### 3.2 义项（一个词的一个意思）

| 字段 | 说明 | 现状 |
|---|---|---|
| 义项号 | 稳定标识 | 有 |
| 英文释义 | 中文释义的依据 | 有，每词截到 8 条 |
| 语域与用法标签 | 粗口、古语、俚语、地区 | 有 |
| 性、数、冠词 | 按义项取值 | 有 |
| 中文释义 | 一个词或短语，最多十个字 | 有（历次审核成果） |
| 用法说明 | 可空 | 有 |
| 类别 | daily、creative 等 8 种 | 有 |
| 可见性 | 普通、只供查询、降权、只认精确输入 | 有 |
| 义项顺序 | 哪个意思默认显示 | **无**；现由人工排（上一轮 399 条） |
| 审核记录 | 状态、审核方、理由、来源 | 有 |

### 3.3 词形（一个写法属于谁）

| 字段 | 说明 | 现状 |
|---|---|---|
| 写法 → 词条 + 词性 | vais → aller（动词） | 有 |
| 语法标签 | 人称、时态、分词、复数、格 | **丢** |
| 去重音、口语缩写的写法 | farò → faro、herum → rum | **无**（实验新发现） |
| 名词变形的性、数、冠词 | hommes → 阳性复数 | 有 |
| 义项级排除 | 「死亡」义的 mort 不认 morte | 有 |

### 3.4 频次（一个词有多常用）

| 字段 | 说明 | 现状 |
|---|---|---|
| 写法的次数 | 字幕前 50,000 个写法 | 有 |
| 「原形 + 词性」的次数 | 选词与排序真正需要的 | **基本无**；只有每语 500 句百科带标注 |
| 档位 | 常用、次常用、其余 | **无**（新增） |

### 3.5 审核

沿用现有结构（状态、审核方、理由、证据位置）。已审义项按「语言 + 规范写法 + 词性 + 中文」回连，不重审。

## 4. 实验结果：原定三条规则

用户 11-19 同意的三条规则，实验（四语，复刻现行选词并与现行候选表逐位核对 5000/5000）结果如下。

| 规则 | 结果 |
|---|---|
| 一、宁收勿漏 | 不能单独成立。不加限制时，la、tu、sur、de、para、plus、peu、Ja、Nein 这类功能词、副词、感叹词同形的冷僻名词会大量混入。功能词、副词、感叹词的整词否决要保留 |
| 二、歧义次数平分 | 能补回大部分漏词（西 13/14、意 12/16、法 14/24、德 7/10），但每语新增 600–840 个补收词，其中常用动词、形容词的变形撞上冷僻名词（fût、aura、son、dije、fu、Habe）约占四成，仍要逐词看。还会让百科型虚高更严重（意 era 529 → 49） |
| 二′、按其他写法加权 | 否决。没有别的写法的词（sens、casa）被压到 0 |
| 三、只分粗档 | 与上两条无关，实验没有测，仍可用 |

**结论**：现有数据上没有一条分配规则能同时消掉漏词和虚高，每种分法都要人工逐词看。真正去掉人工判断需要带词性的词频来源。

## 5. 现行收词规则（供用户重看）

按处理顺序列出。「实验」一栏只说本次实验测到的情况；准入与显示规则（A 组）实验没有动。

### S 组：选词（`review/lexicon-rebuild-20261118/select.py`）

| 号 | 规则 | 依据 | 实验 |
|---|---|---|---|
| S1 | 三个频率源：字幕前 50,000 个写法、每语 500 句百科（2 倍权重）、两部公版文学；按 1/(60+名次) 融合；百科、文学里原形至少出现 3 次 | RULES.md「频率与名额」 | 百科 2 倍造成语域虚高；每语 13–38 个只在百科出现的词（achéménide、polonio、mazedonisch）全进前 1,000 名。权重降到 1：estado 50 → 109，maison 211 → 126 |
| S2 | 每种现代语取前 5,000 个原形；同一词头多义不重复占名额 | 同上 | 法语仍缺的词有一半落在 5,039–5,886 名 |

| S4 | S3 的例外：另一原形的原形写法在字幕里不到本写法 1/20 时，次数归本词；但「共用词形否决表」（74 行）里的写法不适用 | 返工（11-19） | Suche、ketten、mauern 仍被误判为本词 |
| S5 | 与专名同形的写法默认不计；「专名同形审定表」（1,024 行）判为普通词主导的才计 | 返工（11-19） | 不查表时 vader、Pinocchio 混入，表仍需要 |
| S6 | 与感叹词同形的写法默认不计；「感叹词同形放行表」（163 行）放行的才计 | 复审（11-19） | 不否决时 Ja、Nein、si 混入 |
| S7 | 写法另有未准入词性的词条（介词、代词、连词、限定词、冠词、小品词、副词、短语、数词）时整词不计 | select.py | 只因「短语」词条被否决的（tonnerre）可以放开；放开副词会让 plus、peu 混入 |
| S8 | 粗口、屏蔽器命中、英语借词表、只有旧义、只有词形义的写法不计 | RULES.md、select.py | madonna 被屏蔽器挡住 |

**语域问题**：可用的来源（dlexDB 书面语、ParlaMint 议会发言）都不是字幕。直接拿它们排名，会重演百科、文学的语域偏差（议会里 estado「国家」本来就高频）。

**建议（西、意、德三语已实测，见实验报告第三至五部分）**：排名仍用字幕词频（FrequencyWords），只在**歧义写法**上用带标注语料算各原形、词性的占比，再按占比拆分字幕次数。占比受语域影响比绝对频次小，但 estado 这类词仍会偏，需要实测。三语都可用 ParlaMint（CC BY 4.0）做占比来源，德语还可用 dlexDB 对照。

**用户决定（11-19）**：西、意、德**只走自建**，不写询问信。许可清楚、能直接用的开源数据就用（ParlaMint、dlexDB、Tatoeba），其余自建。

**实测结果（11-19）**：

| 语言 | 漏词补回 | 虚高 | 前 5,000 换掉 | 剩下的事 |
|---|---|---|---|---|
| 西 | 13 / 14 | cristo 落下；estado 仍 46 | 775 | 核对表：estado、cometa |
| 意 | 15 / 16 | trovato 出局；faro、verro 反升 | 954 | D5 登记漏重音写法（farò、verrò） |
| 德 | 9 / 10 | ketten、mauern 出局；Rum、Suche 仍高 | 671（更正后） | 原形更正表已做（143 条，见实验报告第六部分）；正式重建时再过第 5,000 名附近 |

德语比西意差（更正前换掉 691 个），原因有三：ParlaMint-AT 把对话里的口语形标错原形（weißt → weißen、typen → Typus、hast → hasten）；字幕词表全小写，Warte / warte、Würde / würde 只能借议会比例，名词偏多；议会语域把 Suche 推高。前两类走更正表，与 D5 同一套机制。

### 6.3 条款不清或受限的来源：只作核对

用户问这些来源能否用来检查。可以，但要守下面几条，做法和词包文件头里「核对时查阅过别的词典，未收录其文字」一致：

| 规则 | 说明 |
|---|---|
| 只对照，不搬数据 | 用于找出自建结果里的可疑词（例如两边名次差很远），每个词由人判断后再改；不把它们的频次、名次、词表写进任何入库文件或词包 |
| 不公开它们的数字 | 报告里只写「对照后改了哪些词、为什么」，不贴它们的频次表或名次 |
| 禁止商用（NC）的来源**不下载**（用户 11-19 定） | SUBTLEX-IT、PAISÀ 是 CC BY-NC-SA。项目本身不收费，但词库按 CC BY-SA 发布、允许他人商用，作者另有社区名气与个人网页导流这类间接利益，算不算「非商业使用」说不清；这些来源只能核对核对表上十来个词，收益小。另一个理由（用户提）：多一个来源，人和模型都要多分一份注意力，也多一处出幻觉的机会 |
| 禁止改编（ND）的来源 | SUBTLEX-DE（CC BY-NC-ND 3.0）同上，不下载 |
| 只能在线查的来源 | EsPal 没有批量下载：只人工逐词查，不写脚本批量抓取（网站条款未知，批量抓取风险高） |
| 许可完全不明的来源 | CORPES、CoLFIS、OpenSubtitles 原文：不下载 |

这不是法律意见。

## 7. 对发布包的影响

发布包格式（`lexicon.v = 2`）尽量不动：

- **第 8 列**从精确名次改为档位（规则三），运行时的排序、随机抽词、候选排序要同步改并补测试。
- **词条数**取决于 D3、D4。方案 ① 每语多 600–840 个词头，体积没有实测。

现有格式的已知毛病（与本次重建无关，备查）：`words` 分区的冠词与义项不按位置对齐；`words` 与 `lexicon.senses` 内容重复；用法说明按词合并，看不出属于哪个义项。
